# Simple Interest Calculator

A beginner-friendly Bash program that calculates simple interest from the principal, annual interest rate, and loan/investment duration.

## Inputs

- `p`: principal amount
- `r`: annual interest rate, expressed as a percentage (for example, enter `5` for 5%)
- `t`: time period in years

## Output

Simple interest calculated using the formula:

```
simple_interest = (p * r * t) / 100
```

For example, `p = 1000`, `r = 5`, and `t = 2` gives a simple interest of `100.00`.

## How to run

Run this script with Bash:

```bash
bash simple-interest.sh
```

Enter the principal, annual rate, and number of years when prompted.
