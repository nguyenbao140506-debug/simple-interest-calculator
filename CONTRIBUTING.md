# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator.

Contributions, bug reports, documentation fixes, testing suggestions, and improvements are welcome.

## Steps to contribute

1. Open an issue describing the bug or enhancement, if one does not already exist.
2. Fork the repository and create a branch for your change.
3. Make focused edits and keep the calculator easy to understand.
4. Test the script with normal, zero, and decimal inputs using `bash simple-interest.sh`.
5. Commit your changes with a clear commit message.
6. Open a pull request describing what changed and how it was tested.

## Style and communication

- Keep Bash code readable and explain non-obvious logic.
- Update the README if the behavior or interface changes.
- Be respectful and follow the project's [Code of Conduct](CODE_OF_CONDUCT.md).
- Do not commit secrets, credentials, or private user information.
